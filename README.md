# Trump Technology & Engineering — website

Public site for [Trump Technology & Engineering](https://trump.tech) (also [trumptechnology.com.au](https://trumptechnology.com.au)).

Static HTML/CSS site hosted on Netlify (`trump-technology-engineering`). Primary domain: **trump.tech**.

## Pages
- `index.html` — home (services, How we work, dashboards, AI Quick Start)
- `about.html` — about
- `contact.html` — Netlify Forms contact (`thanks.html` confirmation)
- `ai-quick-start/` — AI Quick Start offer (A$999)
- `shared.css`, favicons, `robots.txt`, `sitemap.xml`

## Local preview
Open the HTML files in a browser, or serve the folder with any static file server.

## Deploy note
Production deploys are managed on Netlify. Do not treat this repo alone as live until the Netlify site is pointed at a commit from here.
